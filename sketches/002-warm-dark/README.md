## Variant: Warm Dark

### 设计立场
温暖暗色，圆角卡片，金色点缀。参照 Claude、Airbnb 的暖色调设计。

### 关键选择
- **布局**: 同样侧栏 + 主内容，但卡片更大更圆润（16px 圆角）
- **配色**: 深黑偏褐 `#0f0f12`，暖金色 `#f59e0b`，玫瑰红 `#f43f5e`，蓝绿色 `#60a5fa`
- **字体**: DM Sans + IBM Plex Mono
- **背景**: 带微妙的暖色径向渐变光晕
- **边框联动**: 正常=暖金色微光边框，断网=玫瑰红发光边框
- **按钮**: 圆角胶囊，暖色系
- **概览区**: 同样三列，但大数字用金色，更醒目

### 优势
- 暖色调有家庭感，适合儿童管控产品
- 对比度适中，长时间使用不累
- 金色点缀有品质感

### 劣势
- 信息密度略低于 Linear 风
- 暖色可能不适合所有用户

### 最适合
- 家庭产品，追求温暖和可亲近感
