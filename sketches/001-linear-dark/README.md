## Variant: Linear Dark

### 设计立场
极简克制，信息密度高，冷色调。参照 Linear、Vercel 的设计语言。

### 关键选择
- **布局**: 左侧窄侧栏 + 主内容区，960px 最大宽度
- **配色**: 深黑底 `#0a0a0f`，紫色点缀 `#8b5cf6`，冷灰文字
- **字体**: Inter + JetBrains Mono
- **卡片**: 玻璃拟态 `rgba(255,255,255,0.03)`，1px 边框
- **边框联动**: 正常=设备色微光边框，断网=红色发光边框+顶部红线
- **按钮**: 圆角胶囊，低对比度，hover 变亮
- **概览区**: 三列并排（大数字 + 迷你柱状图 + 设备占比条）

### 优势
- 信息密度高，适合数据仪表盘
- 冷色调克制，不抢眼
- 紫色系有辨识度

### 劣势
- 对比度偏低，长时间看眼睛累
- 缺少温度感，不太像"家庭"产品

### 最适合
- 工具型产品，追求效率和密度
